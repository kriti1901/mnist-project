Annotation & Commentary

3Blue1Brown Integration: This dashboard aligns Keras codebase parameters (layers, sizes, cost, backprop) with the classic 3B1B Neural Network explanation sequence (Chapters 1 to 4).

Chapter 1: Neurons & Multi-Layer Feedforward

a^{(l)} = \sigma\left(\sum_{j} w_{ij}^{(l)} a_j^{(l-1)} + b_i^{(l)}\right)
A neuron is simply a container holding a number (activation, $a$). The input layer activates based on raw pixel grayscale values. Sub-layers calculate weighted sums of the previous activations plus a threshold bias. The Sigmoid function $\sigma(z) = 1/(1+e^{-z})$ squishes the sum between $0$ and $1$, representing neuron confidence.

Chapter 2: Cost Functions (MSE vs Cross-Entropy)

\mathcal{L} = -\sum y_i \log(\hat{y}_i) \quad \text{vs} \quad \text{MSE} = \sum (y_i - a_i)^2
The cost/loss function evaluates network error. While 3Blue1Brown utilizes Mean Squared Error (MSE) for intuitive calculus, our codebase implements Sparse Categorical Cross-Entropy. Cross-Entropy penalizes incorrect confidences exponentially, accelerating gradient step updates and resolving neuron saturation problems during backpropagation.

Chapter 3: Gradient Descent & Learning Rates

W_{new} = W_{old} - \alpha \nabla C(W)
A network trains by stepping down the multi-dimensional cost landscape along the negative gradient vector. In Keras, we compile our optimizer using 'adam', which adapts individual learning rates ($\alpha$) dynamically based on rolling average momentum, rendering descent more stable than constant step-size gradient descent.

Chapter 4: The Calculus of Backpropagation

\frac{\partial C}{\partial w_{jk}^{(l)}} = \frac{\partial z_k^{(l)}}{\partial w_{jk}^{(l)}} \frac{\partial a_k^{(l)}}{\partial z_k^{(l)}} \frac{\partial C}{\partial a_k^{(l)}}
The derivatives of the cost function with respect to weights are recursively calculated from the final layer backward using the mathematical chain rule. Modern neural frameworks like PyTorch use automatic differentiation graphs, enabling exact derivative calculations without manual derivation of the multi-layer calculus structures.
